# Third-party notices

PokeShare bundles or derives from the following open-source work.

## besteon/Ironmon-Tracker — MIT

The per-version Gen 3 RAM addresses in `packages/data/src/games.ts` are ported
from Ironmon-Tracker's `ironmon_tracker/GameAddresses/*.json`, which has the
best-tested Gen 3 address tables available.

<https://github.com/besteon/Ironmon-Tracker>

## pret decompilations — see each project

`packages/data/src/mapsec.generated.ts` is generated by `scripts/gen-mapsec.py`
from the `region_map_sections.json` data files in:

- <https://github.com/pret/pokeruby>
- <https://github.com/pret/pokeemerald>
- <https://github.com/pret/pokefirered>

## mGBA — BSD 2-Clause (Jeffrey Pfau / endrift)

The save-state layout in `packages/gba/src/savestate.ts` follows
`include/mgba/internal/gba/serialize.h`. The emulator core is consumed as the
`@thenick775/mgba-wasm` package via `thenick775/gbajs3`.

- <https://github.com/mgba-emu/mgba>
- <https://github.com/thenick775/gbajs3>

## No game assets

This repository contains **no ROMs and no assets ripped from any Pokémon game**.
Players supply their own ROM, which is loaded from local disk into their own
browser and never uploaded. Pokémon and Game Boy Advance are trademarks of their
respective owners; this project is unaffiliated with and unendorsed by them.
